House Price Exploratory Data Analysis & Linear Regression

This project performs Exploratory Data Analysis and builds a Simple Linear Regression model on a house price dataset. The goal is to identify housing price patterns, treat missing values and outliers, and analyze the direct relationship between a home's square footage and its market price.

Files Included:

Jupyter Notebook (.ipynb): Contains the Python code for data cleaning, descriptive statistics, data visualization, and machine learning model training.

PDF / Word Report: Contains the visual charts, observations, and top key findings from the analysis.

Dataset (.csv): The raw data used for the analysis.
